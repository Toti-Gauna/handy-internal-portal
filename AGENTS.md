# Instrucciones para el repositorio

- Revisá el índice en [`docs/README.md`](docs/README.md) antes de cambiar arquitectura, datos, permisos o comportamiento.
- La vista disponible solo muestra ejemplos ficticios. No conectes datos reales hasta que existan contratos y autorización server-side aprobados.
- No agregues campos personales sensibles, secretos, autenticación improvisada, almacenamiento administrativo local ni endpoints supuestos.
- Toda transición requiere decisión backend y auditoría; la UI de muestra mantiene las acciones bloqueadas.
- Actualizá los documentos del módulo junto con los cambios de comportamiento conforme a TECH-12.
